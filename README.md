# INFN-Intership
Characterization and qualification of devices and test structures from the pre-production of sensors for the Endcap Timing Layer detector of the CMS experiment.

## HPK QC-TS
The goal is to validate the productor analysis on HPK pre-series test structures. After performing CV characteristic the value of V_gl il extracted. It is defined as the crossing point of the lines that describe the linearity in the build region and in the gain region.

## FPK Charge Stability
The objective of the analysis is to verify that the charge generated in the sensor by a beta particle (a beta radiation source has been used) remain stable over time. The original file .root is not visible because too heavy.
